# known-failures.txt -- the specs this bundle is known to fail.
#
# One "UNIT: TEST" per line, matching the runner's own `FAIL:` lines verbatim.
# Blank lines and #-comments are ignored.
#
# BY NAME, NOT BY COUNT.  A budget of "2 failures" is satisfied by fixing one
# and breaking another, which is the exact event a ratchet exists to catch.
# Names catch it; a number cannot.
#
# THE LIST MAY ONLY SHRINK.  tests/spec-gate.sh is red when a failure appears
# that is not here, AND when a line here starts passing.
#
# WHY THERE ARE ONLY TWO
#
# This list describes x-ash on x-engine-c v0.1.3, which x-lang v0.7.1 is the
# first release to pin.  Before that pin the bundle was dead at load -- 80 of
# 82 red -- because v0.1.2's x_prim_make_token_base segfaulted on the first
# character of any input, and an isolated tokenizer base is the one thing this
# bundle cannot do without.
#
# Those 80 were never recorded here, deliberately.  Recording them would have
# enshrined a platform bug this bundle did not cause as debt this bundle owns,
# would have been torn up the day the pin moved -- which is today -- and would
# have buried the two failures that are actually ash's.
#
# The two below ARE ash's, and they are what this file is for.

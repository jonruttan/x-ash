# known-failures.txt -- the specs this bundle is known to fail.
#
# One "UNIT: TEST" per line, matching the runner's own `FAIL:` lines verbatim.
# Blank lines and #-comments are ignored.
#
# Listed by name, not by count: a budget of N failures is satisfied by fixing
# one and breaking another, which names catch and a number cannot.
#
# The list may only shrink. tests/spec-gate.sh is red when a failure appears
# that is not here, and when a line here starts passing. An empty list means
# every spec passes and any new failure is a regression.
